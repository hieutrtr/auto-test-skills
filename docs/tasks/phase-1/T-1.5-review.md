  - `awk -F= '$1==k {sub(...); print}'` is POSIX awk.
  - `sed -E 's/...//'` is POSIX `-E` extended regex.

## 10. Lessons captured for downstream tasks

1. **Pipeline ordering with finalize-run.sh** — finalize writes a placeholder
   `run.json` AFTER initialization. Any orchestrator wanting the parsed
   `run.json` to land in the run dir must merge POST-finalize. Documented
   in run.sh; T-1.6 retention should be unaffected (it touches whole run
   dirs, not individual JSON files).

2. **Bash 3.2 + macOS default**: avoid associative arrays; if you need a
   dict-like lookup, write the data to a tmp file and `awk -F=` over it
   (used in render-dashboard.sh).

3. **Skill discovery** (R-A from INDEX §10): orchestrate.sh resolves the
   sibling skill via simple path math, no Claude-runtime dependency. This
   means installing skills under `~/.claude/skills/` works as long as the
   two folders sit side-by-side.
