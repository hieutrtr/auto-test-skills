## 3. Self-Review Checklist

- [x] **AC measured?** All 18 ACs map to ≥ 1 assertion (table §2). 91 new assertions
      this iter (36 append + 55 finalize). Plus 35 inherited from T-1.1.

- [x] **Reproducible?** Every test uses a throwaway `mktemp -d` resolved with `pwd -P`;
      no host-state leakage. `latest` symlink target is asserted, not just its existence.
      Golden compare normalizes only the **timestamp / path** fields — schema-shape changes
      will reliably break the golden.

- [x] **Skill frontmatter valid?** `validate-skill.sh` reports 8/8 PASS. Description
      remains 906 chars; the `centralize test logs` trigger phrase + 5-anti-pattern
      enumeration are unchanged. T-1.2 (pending) markers in body have been replaced
      with the actual T-1.2 surface (append + finalize forms).

- [x] **No secret leak?** Scripts read no env vars beyond `PATH`. JSON values are
      escaped through `python3 json.dumps` (with `sed` fallback) — no quote injection.
      Test temp dirs are purged via `trap rm -rf $TMP_RAW EXIT`.

- [x] **Cross-platform?**
      - `date -u +%Y-%m-%dT%H:%M:%SZ` — POSIX, identical BSD + GNU.
      - `python3` ms timestamp; falls back to `date +%s000`.
      - `cat src >> dst` — POSIX append.
      - `mv -f tmp final` — POSIX atomic rename.
      - `ln -sfn run_id latest` — works on BSD (unlink+symlink) and Linux (rename(2));
        end state is consistent (atomic w.r.t. consumer view).
      - Per-layer streams + `O_APPEND` for atomicity ≤ PIPE_BUF — POSIX guarantee
        cited in `append-log.sh` header.
      - **No** `stat -c`, `date -d`, `gzip --keep`, `readlink -f`, `find -printf`,
        GNU `sed -i`, `mapfile` (bash 4+) — verified by manual scan + the harness
        runs cleanly on macOS bash 3.2.57.

- [x] **No bash-4-isms?** Caught and fixed during dev: replaced `mapfile -t`
      → portable `while IFS= read -r _l; do arr+=("$_l"); done` (bash 3.2 safe).
