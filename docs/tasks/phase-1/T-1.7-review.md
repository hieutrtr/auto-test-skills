## 4. Self-review checklist (Rule 3)

- [x] **AC measured?** — yes, table §3.
- [x] **Reproducible?** — `bash tools/tests/test-validate-skill.sh` is hermetic. Production skills are read-only (linter does not write). Negative fixtures are static under `tools/tests/fixtures/`. The empty-root check uses `mktemp -d` with a trap-on-EXIT cleanup. No wall-clock or network dependence.
- [x] **Skill frontmatter valid?** — all 3 production SKILL.md still pass after T-1.7 (no body modifications). Positive cases in the test confirm.
- [x] **No secret leak?** — no env reads, no API keys, no hardcoded paths outside the project tree. Negative fixtures contain only deliberately-broken markdown.
- [x] **Cross-platform (macOS / Linux), no GNU-only flags?** — audited:
  - `awk '/^---$/{n++; if(n==2){print NR; exit}}'` — POSIX awk only; no `getline`, no `gensub`, no `printf %c`.
  - `head -n1` — POSIX (vs GNU `head -1` which is also accepted on BSD, but `-n1` is canonically portable).
  - `sed -n "2,$((FM_END_LINE-1))p"` — POSIX `sed` address range; BSD- and GNU-compatible.
  - `grep -E` — POSIX ERE.
  - `printf '%s\n'` — POSIX.
  - `[[ "$x" == "$y" ]]`, `[[ "$x" =~ ... ]]` — bash 3.2+ only (matches the toolchain established in T-1.1..T-1.6).
  - `mktemp -d` — POSIX-compatible on macOS BSD + Linux GNU (no `--tmpdir` / no `-p` flag).
  - `cd "$(dirname "$0")" && pwd` — portable readlink-free directory anchor (matches T-1.1..T-1.6 pattern).
  - **No** `stat -c`, **no** `date -d`, **no** `find -printf`, **no** `sed -i`, **no** `gzip --keep`. Bash 3.2 syntax only.
  - `bash -n` syntax check passes on all 4 new shell scripts.
- [x] **Lint-all does not stomp on `spike/`** — `lint-all.sh` defaults to `<repo>/skills/`, never recurses into `spike/`. Verified by inspection (no `find` over the repo root).
