## 5. Risks + Mitigation

| # | Risk | Mitigation |
|---|---|---|
| R-1 | Sub-second collisions on parallel `init-run` calls | Counter-suffix loop (`run-id-1`, `-2`, …); Test T1.1-8 exercises |
| R-2 | BSD `date` lacks ms precision (`%N` is GNU-only) | Use `python3 -c 'time.time()*1000'` with `date +%s000` fallback (carry from spike) |
| R-3 | JSON escape of project path containing spaces / quotes | `python3 -c json.dumps(...)` with `sed` fallback (carry from spike `finalize-run.sh:40-43`) |
| R-4 | User passes `--`-prefixed flag as project_root | Use `getopts`-free positional parsing; `[[ ! -d ]]` guard in AC-7 |
| R-5 | Frontmatter description too short or missing trigger phrase → Claude Code does not auto-trigger | Apply T-0.1 §5 4-part template; validate with `validate-skill.sh` in review |
| R-6 | Future T-1.2 will need `latest` re-point — this iter must not preemptively create a broken symlink | Explicitly **do not** touch `latest` here; documented in §4 out-of-scope |
