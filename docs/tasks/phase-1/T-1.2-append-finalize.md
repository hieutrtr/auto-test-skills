## 1. Title (from plan)

> `append-log.sh` + `finalize-run.sh` (tính `duration_ms`, update manifest).

Loop-step refinement (this iter):

- `append-log.sh` streams stdout/stderr **line-buffered** to per-layer files
  (`streams/<layer>.log`) with an **ISO-8601 UTC timestamp prefix** on every line, plus a tee
  to `streams/all.log` for live-tail UX (carry from spike).
- `finalize-run.sh` reads `meta.json` (T-1.1 contract), merges per-layer streams in fixed
  order into the canonical `run.log`, computes `duration_ms`, promotes the placeholder
  `summary.json` into its final form (`status`, `exit_code`, `duration_ms`, parsed counts,
  absolute `log_path`), writes the rich `manifest.json` per ARCHITECTURE §(b), writes a
  `run.json` placeholder (suites filled by T-1.4), and atomically re-points
  `<project>/.test-runs/latest` via `ln -sfn` (POSIX `rename(2)`).

## 5. Risks + Mitigation

| #   | Risk                                                                                                              | Mitigation                                                                                                                                  |
| --- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| R-1 | Finalize reads `meta.json` (JSON) instead of spike's `.meta` (k=v) — parsing differs                              | Use `python3 -c json.load` with `awk`-grep fallback (graceful when python3 absent); both produce same field strings                          |
| R-2 | `ln -sfn` semantics differ across BSD vs GNU (BSD's `-h` flag absent on linux but `-fn` works on both)            | Verified `ln -sfn` is BSD + GNU compatible (rename(2) on linux; unlink+symlink on BSD). Use `( cd "$runs_root" && ln -sfn "$run_id" latest )` for relative target |
| R-3 | Per-line ISO-ts prefix breaks downstream `cat run.log \| grep <test-name>` patterns                               | Prefix is space-separated; user can `awk '{$1=""; print}'` to strip. Document in `references/schema.md`. Loop step explicitly asks for ts prefix |
| R-4 | Stdin-form `read -r` strips trailing whitespace and converts `\r\n` to `\n`                                       | Acceptable for log viewing; document. Carries from spike behavior (no change)                                                                |
| R-5 | summary.log_path becomes invalid if user moves `.test-runs/` between hosts                                        | Absolute path tradeoff documented; manifest.json keeps its own `log_path` (also absolute for consistency). Restoring portability deferred to Phase 4 |
| R-6 | Mid-finalize SIGKILL leaves `*.tmp` files around                                                                  | `*.tmp` files are pre-rename only; `mv -f` is atomic; even if killed before mv, the prior summary.json (T-1.1 placeholder) is still valid     |
| R-7 | `finalize-run.sh` called twice on same run-dir produces incorrect `duration_ms` second time                       | Defined behavior: second call recomputes `duration_ms` from the **same** `meta.started_epoch_ms`, which still works (non-mutating). Not a real risk |
| R-8 | T-1.4 may need extra fields in manifest (e.g. `runtime`, `node_version`) not present here                         | Forward-compatible schema (`schema_version: "1"`); T-1.4 can additively extend without breaking T-1.2 consumers                              |
