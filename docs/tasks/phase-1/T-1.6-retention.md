### 4.3 Test seed helper (inside test file)

```bash
seed_run() {
  # $1 runs_root  $2 ts (e.g. 20260101T010101Z)  $3 stamp (text payload to verify gunzip)
  local rr="$1" id="$2" tag="$3" rd="$1/$2"
  mkdir -p "$rd/streams" "$rd/screenshots"
  printf 'unit log %s\n'   "$tag" > "$rd/streams/unit.log"
  printf 'all log %s\n'    "$tag" > "$rd/streams/all.log"
  : > "$rd/screenshots/foo.png"
  printf 'merged %s\n'     "$tag" > "$rd/run.log"
  printf '{"run_id":"%s"}\n' "$id" > "$rd/run.json"
  printf '{"run_id":"%s"}\n' "$id" > "$rd/manifest.json"
  printf '{"status":"passed"}\n' > "$rd/summary.json"
  printf '{"run_id":"%s"}\n' "$id" > "$rd/meta.json"
}
```

12 seeded ids span e.g. `20260101T010001Z`..`20260101T010012Z` (lex-sortable
matches age order).

## 5. Risk + mitigation

| ID  | Risk                                                        | Mitigation                                                            |
|-----|-------------------------------------------------------------|------------------------------------------------------------------------|
| R-1 | gzip flag drift between BSD (macOS) and GNU (Linux)         | Use plain `gzip <file>` (no `--keep`, no `-k` BSD-only). Verified by spike memo §1 |
| R-2 | Sort by name fails when `-N` collision suffixes mix in      | Sort emits `YYYYMMDDTHHMMSSZ` < `YYYYMMDDTHHMMSSZ-1` lex-naturally; tested via R12 |
| R-3 | `latest` symlink swept up as a "run dir"                    | Skip via `[[ -L "$entry" ]]` check                                     |
| R-4 | Compaction during another skill's tests breaks isolation    | Default OFF; opt-in via `TEST_LOG_RETAIN=1` env on `finalize-run.sh`   |
| R-5 | Re-gzip on second pass produces `run.log.gz.gz`             | Skip when `run.log` absent OR `run.log.gz` already present             |
| R-6 | Race when two finalize calls retain in parallel             | Phase 1 is single-process; doc as "parallelize on Phase 4 if needed"   |
| R-7 | retention sweeps a non-test dir if user `mkdir`s under .test-runs | Whitelist: dirname matches `^[0-9]{8}T[0-9]{6}Z(-[0-9]+)?$` only |
