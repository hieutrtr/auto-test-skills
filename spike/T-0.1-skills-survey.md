## Approach

**Spike, research-only — no code, no test.**

1. `ls ~/.claude/skills/` — liệt kê user-level skill (chỉ có `drawio`).
2. `find ~/.claude -type d -name "document-skills"` — locate bundled marketplace cache.
3. Đọc `SKILL.md` head 20 lines của 5 skill: `drawio`, `webapp-testing`, `xlsx`, `pdf`, `docx`.
4. Bonus: đọc body `skill-creator/SKILL.md` (canonical guidance từ Anthropic về cách viết skill).
5. Liệt kê file layout từng skill (scripts/, references/, examples/, LICENSE.txt).
6. Tổng hợp:
   - Frontmatter table (field → required → semantic → example).
   - File-layout table (folder → purpose → loaded into context?).
   - "Loadable" checklist (folder name = name frontmatter; drop ở `~/.claude/skills/`; metadata always in context).
   - Implication cho `auto-test-skills` Phase 1 (8 skill modular, mỗi skill có scripts/ helper).

Output: `spike/skills-survey.md` (~ 200-300 dòng markdown).
